# Aperture Placeholder Brand Assets

Phase 2 uses a production-safe CSS/SVG-style aperture mark in `src/components/brand.tsx` as the initial brand placeholder.

Final Phase 8 brand work should replace or extend this with:
- logo mark
- wordmark
- favicon
- app icon
- Open Graph image
- dark/light-safe variants
- licensed media source notes

Do not use AI-generated raster text as the final wordmark.
