# Next.js Fintech UI

## Overview
Use this skill to build a polished fintech interface that feels like a serious AI financial workspace, not a generic SaaS template.

## UI Rules
- Use Next.js App Router and Server Components by default.
- Push Client Components down to charts, filters, forms, tabs, and streaming AI panels.
- Use shadcn/ui primitives where possible.
- Keep dashboard layouts dense, readable, and responsive.
- Use dark-first metal/glass styling with restraint.
- Use fixed responsive chart containers to prevent layout jumps.
- Mobile should use dedicated navigation and stacked/tabbed content, not squeezed desktop grids.
- Do not build fake AI cards for final demo states.

## Required Surfaces
- Marketing hero, product page, pricing, security, footer/header.
- Authenticated dashboard shell.
- Portfolio, watchlist, research, goals, risk, settings, billing.
- AI streaming panel with citations, data freshness, safety label, and disclaimer.
