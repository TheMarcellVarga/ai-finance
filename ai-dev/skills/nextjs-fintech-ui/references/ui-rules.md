# Next.js Fintech UI Rules

## Aesthetic
- Dark-first, premium, metal/glass.
- Dense but calm information design.
- Strong metric hierarchy.
- Ticker and numeric values may use monospace.
- Avoid generic gradient SaaS hero layouts.

## Interaction
- Charts need stable dimensions.
- AI citations should be inspectable.
- Risk labels should be clear without relying on color alone.
- Mobile layouts should prioritize the main task per screen.

## Avoid
- Marketing-only landing page as the whole product.
- Cards nested inside cards.
- Tiny unreadable chart labels.
- Uncited AI claims.
