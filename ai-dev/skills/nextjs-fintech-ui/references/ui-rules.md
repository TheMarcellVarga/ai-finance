# Next.js Fintech UI Rules

## Aesthetic
- Dark-first, premium, metal/glass.
- Dense but calm information design.
- Strong metric hierarchy.
- Ticker and numeric values may use monospace.
- Avoid generic gradient SaaS hero layouts.

## Brand And Media
- Generate original logo concepts, then produce final wordmark/icon assets without relying on AI-rendered text.
- Use licensed stock images/videos for product pages when they support the financial intelligence story.
- Good media themes: market infrastructure, analyst workstations, financial districts, data centers, abstract market motion, premium device/dashboard shots.
- Avoid generic smiling office photos, unrelated luxury imagery, and dark decorative video that hides the product.
- Videos must be muted, compressed, short-looping, poster-backed, and respect reduced-motion preferences.

## Interaction
- Charts need stable dimensions.
- AI citations should be inspectable.
- Risk labels should be clear without relying on color alone.
- Mobile layouts should prioritize the main task per screen.

## Taste Skill Pairing
- Use Taste Skill for frontend craft review once screens exist.
- Use `image-to-code-skill` when translating the inspiration screenshot into UI.
- Use Taste Skill alongside stock media and generated branding passes to avoid generic SaaS composition.
- Do not let Taste Skill override finance compliance, AI safety, or app architecture rules.

## Avoid
- Marketing-only landing page as the whole product.
- Cards nested inside cards.
- Tiny unreadable chart labels.
- Uncited AI claims.
